- An Android app, first steps (`android/`): a native skeleton in Kotlin and Jetpack Compose that reads the public API
  and shows the weather of one town (now, the next days, the alert level around it) and the activity verdicts of four
  spots, in French, with the colours of the family's visual charter. Not published anywhere; built with the command-line
  tools and tried on one phone. See [`android/README.md`](android/README.md).
